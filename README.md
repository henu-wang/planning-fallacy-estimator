# Planning Fallacy Estimator

Correct for planning fallacy by comparing estimates to actual outcomes

## Features

- Track project estimates vs actual completion times
- Calculate your personal optimism bias coefficient
- Generate corrected estimates based on historical data
- Reference class forecasting integration
